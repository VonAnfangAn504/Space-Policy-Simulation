**Space Policy Simulation**

**Overview**

This repository contains the input data, source code, simulation outputs, and network analysis materials associated with our study.
The repository is organized into four directories to facilitate transparency, reproducibility, and further examination of the simulation procedures and findings.

**Repository Structure**

01_Data: Agent Profile Data

This directory contains the agent-level input datasets used in the LLM-based simulations.

trait_data_com: Agent profiles and attributes for commercial organizations.

trait_data_gov: Agent profiles and attributes for government organizations.

trait_data_univ: Agent profiles and attributes for universities.

These datasets provide the organizational characteristics used to construct agent profiles for the simulations.


02_Code: Simulation Source Code

This directory contains the source code used to implement the baseline and dynamic simulations.

Main Model

Space_Policy_M_MainModel: Source code for the baseline collaboration network simulation.

Dynamics Model

Space_Policy_S1_AnchorExit: Source code for Scenario 1 (Anchor Node Exit).

Space_Policy_S2_NewEntrant: Source code for Scenario 2 (New Entrant).

Space_Policy_S3_PolicyReversal: Source code for Scenario 3 (Policy Reversal).


03_Results: LLM Simulation Outputs

This directory contains the recorded outputs generated by the LLM-based simulations.

Main Model

answer_sheet: Recorded outputs from the baseline simulation.

Dynamics Model

Scenario 1: Anchor Node Exit

answer_sheet_S1_Diffusion_phase1 to phase3

answer_sheet_S1_Mission_phase1 to phase3

Scenario 2: New Entrant

answer_sheet_S2_Diffusion_phase1 to phase3

answer_sheet_S2_Mission_phase1 to phase3

Scenario 3: Policy Reversal

answer_sheet_S3_D2M_phase1 to phase3

answer_sheet_S3_M2D_phase1 to phase3

D2M denotes a transition from diffusion-oriented to mission-oriented policy, while M2D denotes a transition from mission-oriented to diffusion-oriented policy.


04_Network: Network Analysis Materials

This directory contains the network analysis materials generated using Gephi.

Main Model

Network analysis materials are provided for the following policy orientations: Diffusion-oriented policy, Mission-oriented policy

For each policy orientation, the directory contains:

Gephi project files containing the constructed collaboration networks.

Excel files containing the calculated network metrics.

Dynamics Model

Network analysis materials are organized into three scenarios:

Scenario 1: Anchor Node Exit

Scenario 2: New Entrant

Scenario 3: Policy Reversal

Each scenario contains the corresponding Gephi project files and Excel files documenting the network analysis results.
